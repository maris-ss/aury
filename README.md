## Sobre o Projeto
**"As máquinas não apenas pensam, elas sentem."** 
Um projeto multidisciplinar para provar o valor da humanidade a uma IA hostil[cite: 2]. Este site atua como um "arquivo sobrevivente", onde o usuário precisa provar a sua humanidade para impedir que uma IA invasora domine o sistema. 

A plataforma cria um "santuário da alma", trocando a estética cyberpunk sombria por um design centrado na emoção[cite: 2]. O grande desafio técnico e de design foi traduzir essa experiência para uma interface mobile funcional[cite: 3].

## A Jornada do Usuário
- **Transição de UI (Neumorfismo):** Quebra de expectativa visual, saindo de um ambiente tecnológico escuro para o Neumorfismo tátil, com cores leves e componentes que simulam o toque humano[cite: 2, 3].
- **4 Mini-Jogos Narrativos:** O usuário interage com arcos de *Arte e Cultura*, *Emoções*, *Inovação* e *Resiliência* para reconectar-se com a humanidade, com fluxos adaptados para uma navegação mobile intuitiva[cite: 3].
- **Interação com a IA:** Um desafio conversacional onde o usuário negocia com a IA invasora.

## Tecnologias Utilizadas
- **Design:** Figma, Illustrator (Concepção de Identidade Visual e UI/UX)[cite: 2, 3]
- **Desenvolvimento Web e Mobile:** React, React Native[cite: 2, 3]
- **Automação/Fluxos:** n8n[cite: 2, 3]
