## Sobre o Projeto
**"As máquinas não apenas pensam, elas sentem."** 
Um projeto multidisciplinar para provar o valor da humanidade a uma IA hostil. Este site atua como um "arquivo sobrevivente", onde o usuário precisa provar a sua humanidade para impedir que uma IA invasora domine o sistema. 

A plataforma cria um "santuário da alma", trocando a estética cyberpunk sombria por um design centrado na emoção. O grande desafio técnico e de design foi traduzir essa experiência para uma interface mobile funcional.

## A Jornada do Usuário
- **Transição de UI (Neumorfismo):** Quebra de expectativa visual, saindo de um ambiente tecnológico escuro para o Neumorfismo tátil, com cores leves e componentes que simulam o toque humano.
- **4 Mini-Jogos Narrativos:** O usuário interage com arcos de *Arte e Cultura*, *Emoções*, *Inovação* e *Resiliência* para reconectar-se com a humanidade, com fluxos adaptados para uma navegação mobile intuitiva.
- **Interação com a IA:** Um desafio conversacional onde o usuário negocia com a IA invasora.

## Tecnologias Utilizadas
- **Design:** Figma e Illustrator
- **Desenvolvimento Web e Mobile:** HTML, CSS, JS, React e React Native
- **Automação/Fluxos:** n8n
